
# Paradise Nursery

## Online Houseplant Shopping Application

Paradise Nursery is a React-based online shopping application
that allows users to explore and purchase beautiful houseplants.

## Features

- Attractive landing page
- Company information
- Plant catalogue with three categories
- 18 unique houseplant products
- Add to Cart functionality
- Dynamic shopping cart quantity
- Increase and decrease product quantities
- Delete products from cart
- Automatic total price calculation
- Redux Toolkit state management
- Responsive user interface

## Technologies Used

- React
- JavaScript
- Vite
- React Router DOM
- Redux Toolkit
- React Redux
- CSS

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Navigate into the project:

cd paradise-nursery

Install dependencies:

npm install

Start the application:

npm run dev

## Redux State Management

Redux Toolkit is used to manage the shopping cart.

The cart supports:
- Adding products
- Increasing quantity
- Decreasing quantity
- Removing products

## Deployment

The application is deployed using GitHub Pages.
